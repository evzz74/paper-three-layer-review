# 论文三层拆解审读 Skill

## 1. 它解决什么问题

读完一篇论文，通常能记住"它做了什么"，但说不清三件事：

1. 作者在路上**跳过了哪几步**（哪些推论没有实验支撑）；
2. 结论的**证据强度**到底几级，"显著提升"能不能支撑"机制成立"；
3. 哪些**缺口**是真缺口，且能变成一个可以动手做的实验。

这个技能把这三件事变成可交付物，而不是读后感。

## 2. 三层框架

```
L0 问题域 ── 这个领域为什么需要这篇论文，还有哪些没解决
 │
L1 还原 ──── 它走过的路（路径链 + 设计选择 + 核心结论）
 │
L2 核查 ──── 这条路撑得住多少（逐条结论对证据、定级、越界判定）
 │
L3 迁移 ──── 路没修完的地方通向哪（缺口四分类 → 可检验假设卡）
```

**三层是递进关系，不是三个可选的写作角度。** L1 未完成不得进入 L2；三层不得合并成一段综述。

L0 是前置层，不占"三层"名额——它是三层的输入前提：L1 的起点回引 `SQ`，L3 的假设锚定 `GAP`/`LIM`。

| 层 | 回答什么 | 关键产出 |
|---|---|---|
| L0 | 领域缺什么、本文瞄准哪一条 | `BG / SQ / GO / GAP / LIM` 五套编号 + 闭合检查 |
| L1 | 作者实际怎么走的 | 路径链（含跳步标记）、8 类设计选择表、`C1…Cn` |
| L2 | 每条结论站得住吗 | 五格核查表、A–D 定级、三项横向检查、**越界判定** |
| L3 | 下一步做什么 | 缺口清单、≥3 张假设卡（≥1 张证伪方向） |

## 3. 四条让它区别于普通"论文总结"的机制

### 3.1 四类标签，不许混写

| 标签 | 含义 |
|---|---|
| `[原文]` | 作者原话或原始数据（逐字 + 位置） |
| `[事实]` | 从原文数据可直接读出、无需解释 |
| `[推断·作者]` | 作者对数据的解释与断言 |
| `[推断·我]` | 你基于原文做的解释 |

最常见的失真是把 `[推断·作者]` 写成 `[事实]`。四标签强制拆开，"实验证明了"这类话就落不了地。

### 3.2 A–D 证据分级 + 必须写理由

- **A** 直接证据：断言与测量对象一致，能排除主要替代解释
- **B** 强间接：有对照与消融，缺机制检验或跨设定复现
- **C** 弱间接：单数据集单种子、基线未公平调参、代理指标、相关性被写作因果
- **D** 无证据/反向：无对照、循环论证、样本不足、只引用他人

只写级别不写"为什么是这个级别"、不指名缺哪一项（样本量/误差棒/种子/对照/基线调参/指标效度），视为未完成核查。

### 3.3 强制越界判定（二选一，不许含糊）

要么点名「`C_k` 的断言超出了证据」，并说明越界类型（外推 / 因果 / 泛化 / 机制 / 价值）；
要么明确写「未发现越界，理由如下」。

这一条是整份报告的地基——没有它，L2 会退化成"逐段复述结果"。

### 3.4 假设卡的双向判别

每条假设必须写出**支持阈值**与**否定阈值**两侧：

```
判别：支持 = 召回率 +≥3 点，p<0.05，3 种子一致
      否定 = 提升 <1 点，或时延增幅 >20%
```

写不出两侧就说明假设还没成形，退回重写。至少一张卡是"证伪作者结论"的方向。

## 4. 固定六问

每次输出必带，顺序固定，**每题附原文位置与置信度（高/中/低）**：

| # | 问题 | 常见糊弄 |
|---|---|---|
| 1 | 为什么做 | "X 很重要"式套话开场 |
| 2 | 怎么做 | 把方法章节翻译一遍 |
| 3 | 发现什么 | 把 Results 段改写成列表 |
| 4 | 支持到哪 | "充分证明了有效性" |
| 5 | 结论成立条件 | "在特定条件下成立"但不写条件 |
| 6 | 还有哪些尚未证明 | "未来还有很多工作要做" |

第 4、5、6 问必须是**核查结论**，不能复述作者。第 6 问分两栏：`领域未解`（L0 中未触及的空白）/ `本文未证`（未做对照、`未检验`的反证条件、低置信度条目）。

## 5. 三条必带提醒

每次输出都要有，放在报告末尾「使用前必读」，且**必须结合本文具体化**：

1. **模拟 ≠ 现实**：本文结论跨过了哪一段（仿真/离线/代理指标），没跨过哪一段（真实部署、长时运行、人机交互）。
2. **"最优"是设定内最优**：作者的 optimal 只在其约束集、搜索空间、基线调参预算、指标与评测集下成立。没给搜索空间说明的比较一律标 `未证明的优位`。
3. **回原文核对**：本报告是二手解读。数字、图表、附录假设、版本（arXiv v1/v2、预印本 vs 正式版）都要自己回原文对一遍，并给出 `核对 N / 一致 N / 存疑 N / 未核对 N`。

## 6. 输出形态

顺序固定（模板见 `assets/report-template.md`）：

```
一句话结论
六问速览表（答案 / 位置 / 置信度）
L0 问题域定位
L1 研究路径
L2 证据核查（全篇重心）
L3 后续假设
使用前必读（三提醒 + 核对清单 + 未读声明）
```

篇幅服从内容：**L2 最重**，L1 短而准，L3 要能直接拿去开题。

## 7. 触发方式

自动触发（`description` 里已埋中英双词）：

- 中文：解析论文、三层拆解、论文审读、批判性阅读、精读/研读论文、组会读书报告、找研究空白与技术局限、梳理科学问题与研究目标、从文献提炼可开题的假设、核查结论是否被证据支撑
- 英文：dissect / critique / appraise a paper, reconstruct research path, audit claim–evidence alignment, grade evidence strength, detect overreach, derive testable hypotheses

手动调用模板：

```
用三层框架拆解这篇论文：<路径或 URL 或全文>
重点：<例如 只看 L2 的基线公平性 / 只要 L3 的假设卡>
原文形态：全文 PDF
```

只给摘要时它会自动降级为「摘要级审读」，并在报告顶部标注所有不可验证项、置信度统一下调。

## 9. 交付前自检 Gate（9 项）

- [ ] 三层齐全、未混层，L1 无评价性语言
- [ ] L0 五套编号齐全，`GO` 有达成判定，闭合检查有结论
- [ ] 六问每条都有原文位置与置信度，无一条是摘要复述
- [ ] 每条 C 都有强度、前提、事实/推断拆分、反证条件
- [ ] 有明确的越界判定（点名或声明"未发现越界"）
- [ ] 假设卡带双向判别，至少一条证伪方向
- [ ] 三条提醒已结合本文具体化
- [ ] 未读 / 无法核实部分已声明
- [ ] 全文无未标注来源的"作者认为"

## 10. 反模式

- 把摘要改写成六段话，就叫答完六问
- 通篇只夸不挑，找不到一处「未检验 / 证据不足」
- 用"作者认为"代替证据核查，用"实验证明了"代替"实验显示了相关性"
- 把 benchmark 提升当成机制被证明
- 假设写成"未来可以进一步研究 X"，没有方向、没有判别标准
- 把 L3 写成对作者的表扬式展望
- 只复述 Limitations 当缺口，漏掉 L2 暴露的前提未验证与基线缺失

## 11. 与相邻技能的分工

| 技能 | 定位 | 与本技能的关系 |
|---|---|---|
| `nature-reader` | 全文中英对照、图表就位的**翻译型精读** | 它负责"读懂"，本技能负责"审读"；可先用它出对照稿，再用本技能核查 |
| `academic-paper-reviewer` | 模拟 5 位审稿人出**评审意见** | 它产出评审结论，本技能产出证据链；本技能的 L2 可直接喂给它做评审依据 |
| `deep-research` | 多源文献**调研与综述** | 它扫领域，本技能拆单篇；L0 的 `GAP`/`LIM` 可与它的综述结论互校 |
| `research-paper-writing` | **写作**改进 | 本技能第 6 问与 L3 假设卡可直接转为写作的 motivation 与 future work |

## 12. 调优建议

- 觉得输出太长：让它"只跑 L2 + 六问"，跳过 L0/L3。
- 觉得太软、挑不出问题：明确要求"必须给出至少两处越界判定"，它能被强制触发。
- 文献池里多篇要对比：先用本技能逐篇出 `C` 编号与 A–D 等级，再做跨篇证据矩阵——直接比等级比直接比结论可靠。
- 出现幻觉引用：检查是否漏掉了「证据索引表」这一步，L2 必须从索引表取，不许凭记忆写。
